### 🎮 Game Launcher EN

A modern game launcher with a user-friendly interface for managing and launching games.
The project was created as a standalone software product and is designed to provide convenient access to installed games and organize your game library.
## ✨ Features

🎮 - Game library management

🚀 - Quick game launch

🖥️ - Modern user interface

⚙️ - Customize launch options

📁 - Select the location of game files

🔄 - Update launcher components

📊 - Display game information

🛠️ - Easy setup

## 🖥️ Supported systems

Currently:

● Windows 10

● Windows 11

Support for other platforms may be added in future versions.

## 📦 Installation

1. Install Java [Download](https://www.oracle.com/java/technologies/javase/jdk21-archive-downloads.html)

2. Go to the [Releases](https://github.com/CodershaWon21/Optimized-game-launcher/releases/tag/Download-optimized)

3. Download the latest available version.

4. Unzip the archive if necessary.

5. Run the launcher file.

6. Follow the instructions within the application.

## 🚀 Usage
After launching the launcher, add the desired games to your library, specify their location, and click the launch button.
All settings can be changed directly in the program interface.
